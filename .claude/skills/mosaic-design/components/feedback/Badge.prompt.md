Status pill for policy/claim state and document-extraction state.

```jsx
<Badge tone="success">Active</Badge>
<Badge tone="warning">Pending Review</Badge>
<Badge tone="danger">Denied</Badge>
<Badge tone="info">From Document</Badge>
<Badge tone="neutral">Draft</Badge>
```

`info` doubles as the "auto-filled from uploaded document" marker in onboarding; `warning` marks fields still missing.
